Verification Bug Post-Mortems

Real corner-case bugs isolated using SVA, VCD waveforms & protocol checks
BUG #01 • PCIe 2.0 DLL Mid-Packet TLP Corruption During Simultaneous NAK DLLP Arbitration Caught by Concurrent SVA

Symptom: Intermittent LCRC mismatches occurred on the RX side exclusively when an RX framing error triggered a high-priority NAK DLLP while the TX arbiter was mid-way through streaming a multi-beat TLP.

Root Cause: The TX arbiter prioritized DLLPs strictly over TLPs without locking the grant across multi-cycle TLP frames, preempting active TLPs mid-packet.

Resolution: Added an atomic packet-lock state until tlp_end asserts, enforcing priority order (DLLP > Replay > New TLP) cleanly at packet boundaries. Verified with a dedicated SVA framing property.

BUG #02 • PCIe 2.0 DLL 12-Bit Sequence Rollover (4095 → 0) Misclassified as Duplicate TLP Caught by Directed Rollover Test

Symptom: After transmitting 4,096 TLPs, packet sequence 0 was silently dropped by the RX DLL as an old duplicate.

Root Cause: Unsigned comparator (rx_seq < next_rcv_seq) evaluated 0 < 4095 as true across the wrap boundary.

Resolution: Replaced unsigned comparison with 12-bit two's-complement signed modular difference (logic signed [11:0] diff = rx_seq - next_rcv_seq;), isolating expected (0), duplicate (diff[11]==1), and out-of-order gaps across rollover.

BUG #03 • AXI4-APB4 Bridge Async FIFO Full/Empty Pointer Race Across Fast-to-Slow ACLK/PCLK Domains Caught by SpyGlass CDC & VCS Waveforms

Symptom: Back-to-back AXI4 INCR write bursts dropped the final beat when ACLK ran 3× faster than PCLK.

Root Cause: Write-side wfull flag compared binary write pointer against unsynchronized read pointer bits during burst back-pressure transitions.

Resolution: Implemented (N+1)-bit Gray-code pointers with 2-FF synchronizers and MSB/2nd-MSB inversion full detection, eliminating SpyGlass CDC structural/functional warnings.
